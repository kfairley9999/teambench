# Changelog

## 0.1.0 — 2026-11-21

- First public release of TeamBench.
- 20 auto-graded multi-agent tasks across planning, tool use, handoffs, recovery, conflicting instructions, and injected tool output.
- Four orchestration patterns: single agent, supervisor-worker, round-robin, and debate.
- Fully offline scripted mock model for CI, plus an optional Gemini live runner.
- Metrics: success rate, pass^k reliability, steps, token estimates, and a failure taxonomy.
- Static HTML report and README leaderboard generated from a committed mock run.
